# 感知之书 · The Art of Feel

一本面向中文初学者的 UI 与动效设计交互电子书。基于 Emil Kowalski skills 的固定源码快照，每个 skill 一章，共 19 章。独立教学编写，非官方出版物。

## 阅读

- 在线阅读：[感知之书](https://kiokku.github.io/ui-motion-book/)。
- 源码仓库：[Kiokku/ui-motion-book](https://github.com/Kiokku/ui-motion-book)。
- 开发预览：`npm install` 后运行 `npm run dev`。
- 离线成品：双击 `output/感知之书.html`，正文、交互、字体均内嵌；外部原文链接仍需网络。
- 构建网站：`npm run build`，产物在 `dist/`。
- 重新导出离线版：`npm run export`。

## GitHub Pages

推送到 `main` 后，GitHub Actions 安装锁定依赖、构建并发布 `dist/`。Pages 发布来源使用 GitHub Actions。项目路径构建命令为 `npm run build -- --base=/ui-motion-book/`；普通本地预览与离线导出仍使用原命令。

原 Skill 文件作为普通文件保存在仓库中，固定提交与许可见下方来源说明；克隆本项目无需初始化子模块。`output/` 为本地产物，离线版需要自行运行导出命令生成。

阅读界面采用“安静精密的设计实验室”：白色正文、浅蓝灰目录与蓝色实验图形，宋体标题搭配系统中文黑体。英文字体 Manrope 已本地打包，许可见 `public/fonts/OFL-Manrope.txt`。不依赖远程字体服务。

## 学习方式

每章包含学习目标、概念讲解、可操作实验、适用边界、可展开速查、即时反馈判断题和真实项目练习。可搜索章节、查阅术语、保存与导出笔记。桌面目录可收起并记忆选择；宽屏右侧展示对应 SKILL.md 原文，随正文主题逐段补全并定位，支持暂停跟随。回看保留已展开内容，章末完整展开；窄屏通过“查看 SKILL.md”打开原文对话框。手机仍从顶部进入术语索引。封面提供可播放、可拖动时间的真实缓动实验，与章节实验共享曲线计算。

答对判断题后可标记已练习。首次标记后 1 天提示复习，后续正确回忆记录按 3、7、14 天延长；提前复习会重新计算间隔。日期由本机时钟计算，不是账户同步或后台通知。学习记录不代表能力认证。

笔记和进度存于当前浏览器的 localStorage，清除浏览器数据会删除记录。离线文件与 HTTP 预览、不同浏览器的存储彼此独立；移动文件时请先导出笔记。存储不可用时界面提示导出备份。

## 实现

React + Vite；CSS、SVG、WAAPI/Motion 构建动效。Sonner 提供真实通知与撤销交互。页面导航即时切换，实验动效用于观察与解释。遵循系统减少动态效果，并可手动启用静阅。键盘操作、移动目录焦点约束和文字缩放均有考虑。

`src/content.js`：章节元数据、第一章和术语。

`src/lessons.js`：原有十四章的递进正文、案例与回忆题。

`src/newChapters.js`：新增 choreograph、gestures、remove-animations 与 learn-taste 四章。

`src/SkillBrief.jsx`：全书 19 章的适用场景、产出、提问示例与实验观察问题。

`src/ChapterStudy.jsx`、`src/vocabulary.js`：主题导航、案例表、回忆反馈和 91 条可检索词典。

`src/reference.js`：每章的代码、参数或判断流程速查。

`src/Demos.jsx`、`src/LearningLabs.jsx`：19 类章首实验，以及提示气泡、弹层、速度投射和侧栏属性对比。

`src/main.jsx`：阅读、目录、笔记、复习与来源页面。

`src/styles.css`：视觉系统、响应式、打印和减少动态效果。

原生运行时、帧预算、移动视口是明确标注的教学模型，不是设备性能检测。未以浏览器测试替代 Expo Release 构建或手机实测。
