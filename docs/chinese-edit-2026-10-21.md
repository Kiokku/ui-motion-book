# 中文书稿润色 · 2026-10-21

本轮使用 op7418/Humanizer-zh（本地安装的 SKILL.md，revision 2026-09-23）的规则编辑现有中文正文。技能来源：https://github.com/op7418/Humanizer-zh 。此次工作是语言润色，不是重新翻译原始技能，也不是一次全面的技术事实审计。

## 编辑范围

通读序章、15 章讲解与练习、术语说明和来源说明。重点修正主语不明、语序生硬、多个动作过度压缩、抽象比喻遮蔽具体行为，以及中英文混用造成的阅读障碍。保留已通顺的内容，不按禁词表批量删词。

章节顺序、标题和小节数量保持不变。原始英文 SKILL.md、来源快照、代码示例、参数、案例表、题目选项与正确答案保持不变。交互实现、学习记录和原文逐步展开逻辑未作修改。

## 部分改写示例

| 原表达 | 改写后 | 原因 |
| --- | --- | --- |
| 让方向在有意义的轴上分歧，让比较在相同任务下发生。 | 围绕布局、密度或操作方式等关键差异设计方案，再用相同任务比较。 | 用具体维度解释抽象表述。 |
| 通用库不应无条件强迫客户主 actor。 | 通用库则不应无条件要求调用方在主 actor 上执行。 | 补足动作，明确“客户”指调用方。 |
| 默认动画 transform 数组和 opacity | 默认优先对 transform 数组和 opacity 做动画 | 修正词性与语序。 |
| 约定给项目自己的 exemplar | 约定部分应引用项目中可供参照的现有实现 | 明确动作并解释英文。 |
| 每个孩子都拒绝缩小 | 每个子元素都拒绝缩小 | 修正直译用词。 |
| 原生的触感，来自输入和画面之间没有裂缝。 | 及时跟随输入的画面，是原生操作感的重要来源。 | 明确含义，保留判断的适用范围。 |

序章中“不要一次调用所有技能，让几个不同任务互相争夺注意力”没有原文依据，已改为本书建议，并明确说明可以按需组合技能。来源页和章末进一步说明中文是独立教学编写，不是逐句翻译。此修改解决该处归因问题，不代表全书每句教学推论都已逐条完成来源审计。
